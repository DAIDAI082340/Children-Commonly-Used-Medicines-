# 兒童常用藥品簡表 (Pediatric Common Medications & Dosage Calculator)

由 **林聖興醫師** 編輯整理，提供兒科醫師、診所新手與醫療照護人員簡易查閱常用小兒藥品劑量、適應症、用法用量及臨床參考數據。

## ✨ 功能特色

- 📱 **PWA 支援（可安裝至手機桌面為 App）**：支援離線查閱、秒速開啟、宛如原生 App。
- 👶 **孩童體重即時試算器**：輸入體重即可自動計算糖漿 (mL)、懸液劑量與錠劑份量。
- ⚡ **常用公斤快捷鍵（6kg ~ 30kg）**：一鍵快速帶入常用體重。
- 🔍 **極速即時搜尋**：支援商品名、學名、病徵及劑量公式關鍵字篩選。
- ⭐ **我的常用藥品收藏**：點擊藥品卡片右上角星號，快速建立個人專屬處方清單。
- 📋 **一鍵複製處方**：方便病歷系統、處方箋記錄快速貼上。
- 🛡️ **無跳動、全平台穩定設計**：iOS / Android 觸控與虛擬鍵盤深度優化，防止頁面縮放與錯位。

## 🌐 線上預覽與部署

本專案為純靜態單頁應用（SPA），可直接啟用 **GitHub Pages** 提供全球高速訪問：
1. 進入 GitHub 儲存庫的 **Settings** > **Pages**
2. **Build and deployment** > Source 選擇 **Deploy from a branch**
3. Branch 選擇 **main** / **(root)**，點擊 **Save** 即可！
